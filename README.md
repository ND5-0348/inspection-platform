# 异地抽样检测管理平台

本项目采用“微信小程序现场端 + Web管理后台 + Node.js API + MySQL + 对象存储”的可移植架构。本机开发后可部署到腾讯云或天翼云Linux环境，生产上线时通过适配器替换数据库、对象存储、域名和密钥配置。

## 当前版本

首个可运行开发版本已经覆盖：

- 管理后台工作台和检测单列表；
- 统一工号登录和服务端角色权限；
- 抽样员网页工作台，支持任务列表、详情、接单和随机抽样；
- 创建检测单；
- 按既有《质检周计划》`.xlsx` 模板批量导入检测单，自动合并同一采购订单及重复物资行；
- 按资质、状态、任务上限过滤候选人员；
- 按工作量权重随机派发；
- 抽样员查看和接受任务；
- 现场输入托盘数、每托盘箱数、每箱件数和抽取件数；
- 生成不重复的“第几托盘—第几箱—第几件”三级随机结果；
- 现场图片签到（照片写入任务、地址、WGS84坐标、定位精度和打卡时间水印，并保存可核对的定位元数据）；每个随机样品单独拍照，照片写入样品编号、地址、WGS84坐标、定位精度和时间水印；
- 接单后可独立拍摄现场货物照片，无需开启定位；照片保存在任务中，可由抽样员和管理员预览，审核后继续保留；
- 中文逆地理编码（局域网默认使用 OpenStreetMap Nominatim，可切换高德/百度）；地图不可用时保留原始坐标，中文检测单地址可作为回退；
- 逐件检测结论、样品照片完整性校验和提交审核；
- 管理员审核通过或退回修改；
- 管理员新增抽检员、设置或重置初始化密码、停用抽检员账号；
- 管理员将抽检员设为休假或恢复启用，休假人员不能登录且不会参与随机派单；
- 删除尚未派发的检测单，并在删除前显示明确的二次确认提示；
- 保存候选摘要、规则版本、结果和操作日志；
- MySQL 5.7/8.0 数据结构、自动初始化和本机持久化；
- 本机MySQL与MinIO容器定义。

当前API默认读取项目根目录的 `.env`，使用本机 MySQL 的独立开发库 `inspection_platform_dev`。首次启动会自动建库、建表并写入演示数据；建单、派单、接单、图片签到、三级随机抽样、照片元数据、检测结论、审核记录和审计日志均会持久化。签到、补充现场照片和逐样品照片使用独立用途标记，文件保存在本机 `data/uploads` 私有目录；上线时可迁移到腾讯云COS或支持S3接口的天翼云ZOS。详细方案见 `docs/后续开发与照片存储计划.md`。

后端会按代码所在位置定位项目根目录的 `.env`，因此从根目录、npm workspace 或编译后的 `dist` 启动都会使用同一份持久化配置。部署时可通过系统环境变量覆盖文件中的同名配置；如需指定其他配置文件，可设置 `DOTENV_CONFIG_PATH`。

## 本机启动

要求：Node.js 20以上、npm，以及本机 MySQL 5.7 或 8.0。当前开发环境连接 `localhost:3306`，数据库名称为 `inspection_platform_dev`。

```powershell
npm.cmd install
npm.cmd run build
npm.cmd run start:local
```

如果本机安全软件限制Vite开发进程，可先执行 `npm.cmd run build`，再用 `npm.cmd run start:local` 启动已经构建的本地版本。

管理后台：`http://127.0.0.1:5173`

API健康检查：`http://127.0.0.1:3300/api/v1/health`

本机演示账号：

- 管理员：工号 `A001`，密码 `Admin@123`
- 抽样员：工号 `S001`，密码 `Sampler@123`

抽样员既可以登录上述网页，也可以从微信开发者工具进入小程序，两端使用同一任务、同一三级抽样位置、现场证据和检测结果。

### 导入质检周计划

管理员在工作台单击“导入周计划”，选择 `.xlsx` 文件即可。系统逐个工作表校验以下18列表头：序号、质检类型、抽样采购订单号、订单行项ID、计划抽检日期、收货单位、供应商名称、物资编码、物资名称、规格型号、抽样样品数、抽样人员、完成样品数、检查状态、联系人、收货人电话、收货地址、备注。

导入规则：同一“抽样采购订单号”生成一张检测单；同一订单内“订单行项ID + 物资编码”相同的重复行合并，并累加抽样样品数和完成样品数。系统保留来源文件名及导入时间；已经存在的采购订单号会跳过，防止重复导入。导入后的来源字段会同时展示在管理员检测单详情、抽样员网页端和微信小程序端。

### 选择人员派发

管理员在待派发检测单旁点击“选择人员派发”，勾选候选抽检员后确认。只选1人时指定派给该人员；选择多人时，按原有工作量权重仅从所选人员中随机派给1人。也可以切换为“全部符合条件人员随机”。列表显示姓名、工号、部门、资质、未完成任务数及不可选原因。

提交时服务端重新校验启用状态、检测资质和任务上限（5个）。所选名单中只要有一人已不符合条件，整次派单就会被拒绝，不会自动扩大或缩小范围。空名单不可提交；已派发订单不可重复派发。审计记录保存管理员选择的范围、实际候选名单、派发前工作量及权重、派单方式与最终人员。

### 抽检员账号管理

管理员登录后，可在“抽检员账号管理”区域新增抽检员，填写工号、姓名、手机号、部门、检测资质和初始化密码。密码采用带随机盐的 `scrypt` 哈希保存，数据库不保存也不返回明文。管理员重置密码后，该抽检员原有登录状态立即失效。

界面中的“删除账号”执行安全停用：账号不能再登录，也不会进入随机派单候选范围，但历史任务、抽样记录和审计日志仍然保留。如果抽检员存在未完成任务，系统会拒绝停用，需先完成或移交任务。

抽检员状态在“抽检员账号管理”的操作栏修改：“设为休假”会让该人员退出派单候选并使现有登录失效；“恢复启用”后可重新登录和参与派单。存在未完成任务时，系统会拒绝设为休假。

检测单列表中的“删除”仅对“待派发”检测单显示。单击后必须在确认框中再次确认；已经派发、执行中或已有抽样记录的检测单不能删除，以保护历史任务和审计数据。

### 访问微信小程序

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，目录选择 `apps/mini-program`。
3. 本机开发使用测试号，项目已经配置 `touristappid`。
4. 启动API后单击“编译”，即可在开发者工具模拟器中访问。
5. 小程序当前自动使用抽样员工号 `S001` 登录，不需要在页面重复输入密码。

开发者工具模拟器可以使用 `http://127.0.0.1:3300`。手机真机中的 `127.0.0.1` 指向手机自身，不能访问电脑；真机本地调试时，应让手机与电脑连接同一局域网，将 `apps/mini-program/app.js` 中的地址改为电脑局域网IP，并允许防火墙访问API端口。正式体验版和生产版必须改为已经备案并配置证书的HTTPS域名。

### 局域网网页访问

网页服务会把同源的 `/api/v1` 请求转发给本机 `127.0.0.1:3300`，因此局域网只需开放网页端口，数据库和 API 保持本机访问。电脑和手机连接同一局域网后，先用手机打开启动脚本输出的 `http://当前WLAN地址:5173/`。该页面用于确认局域网连通、下载证书并提供 HTTPS 入口。安装并信任证书后，再打开 `https://当前WLAN地址:8443/` 使用管理页面及拍照定位签到。HTTP 不提供登录和业务操作。

在项目根目录双击 `启动系统.cmd` 即可启动。脚本会在服务未运行时安装缺失的依赖、构建最新代码、启动 API 与网页服务，并显示局域网访问地址。重复运行会识别已启动的服务，不会重复占用端口。也可以在 PowerShell 中执行：

```powershell
powershell.exe -NoProfile -File tools\start-lan.ps1
```

Windows 防火墙需允许 `node.exe` 接收局域网内对 5173/TCP 和 8443/TCP 的连接。电脑本机的 `http://127.0.0.1:5173/` 仍可用于定位调试。电脑需保持开机。WLAN 地址变化后，重新运行脚本；脚本会检测新地址、更新服务器证书，并输出新的访问链接。

### 打卡地址显示

本机 `.env` 使用 `MAP_PROVIDER=osm` 时，拍照签到和样品拍照会把 GPS 坐标发送到 OpenStreetMap Nominatim 逆地理编码服务，并优先请求中文地址。电脑需要能连接互联网。服务端会缓存相近坐标并限制请求频率；请遵守 [Nominatim 使用政策](https://operations.osmfoundation.org/policies/nominatim/)。多人高频使用时，可配置 `MAP_PROVIDER=amap` 与 `AMAP_WEB_SERVICE_KEY`，或 `MAP_PROVIDER=baidu` 与 `BAIDU_MAP_AK`。`MAP_PROVIDER=none` 禁用外部地图请求。

地图不可用时，系统会保留 GPS 坐标并显示中文检测单地址；检测单地址只有英文时显示“定位地址暂未解析”，避免把英文订单地址当成真实定位地址。旧签到照片里的水印不会改写；旧记录的页面地址会按已保存的 GPS 坐标重新显示中文结果。

如果手机连 HTTP 指引页也打不开，核对手机 Wi-Fi 的 IPv4 地址与电脑是否在同一网段（例如都以 `192.168.1.` 开头）。若手机能打开电脑的其他网页，却打不开 5173 端口，可在电脑上双击 `修复手机访问.cmd`，按 Windows 提示批准管理员权限；它只为 WLAN 上来自本地子网的访问放行本系统 5173/8443 TCP 端口。然后再试 HTTP 指引页。若仍无法连接，检查访客网络、路由器“AP 隔离 / 客户端隔离”及电脑上的 VPN 局域网访问设置。如果指引页可以打开，但 HTTPS 工作台显示证书错误，按页面提示安装并信任局域网 CA 证书。

局域网 HTTPS 使用保存在当前 Windows 用户目录 `AppData/Local/InspectionPlatform/lan-tls` 的私有密钥和证书。私钥不得发送给其他设备。手机首次访问前，从脚本输出的 `http://当前WLAN地址:5173/lan-ca.crt` 下载公开的局域网 CA 证书，并核对其 SHA-256 指纹 `DA:5B:76:EA:B9:62:EC:7A:68:F9:EB:B2:B9:71:CB:04:3E:46:C1:86:91:BC:D2:3A:B4:52:8E:44:0F:9F:99:53`，再在手机系统中安装和信任。iPhone 安装后还需在“设置 → 通用 → 关于本机 → 证书信任设置”中启用完全信任；Android 的具体入口因品牌而异，可在设置中搜索“安装 CA 证书”。在证书被设备信任前，不要跳过浏览器证书警告。WLAN 地址变化时只需重新签发服务器证书，已信任的 CA 证书和指纹保持不变。

## MySQL配置

实际密码只写入被忽略的 `.env`，不要提交到版本库。配置示例：

```dotenv
DATA_DRIVER=mysql
DATABASE_URL=mysql://root:change_me@localhost:3306/inspection_platform_dev
```

如电脑尚未安装 MySQL，也可在安装 Docker Desktop 后用 `infra/compose.yaml` 启动隔离的 MySQL/MinIO 环境；该容器配置使用端口 `3307`，需同步修改 `DATABASE_URL`。当前电脑已直接使用本机 `3306`，无需启动容器。

## 三级实物位置抽样

现场人员在接单和定位签到后：

1. 选择产品及批次；
2. 输入托盘数；
3. 输入每托盘箱数；
4. 输入每箱件数；
5. 输入需要抽取的件数；
6. 系统随机生成不重复的托盘号、箱号和件号。

例如输入 `2托盘 × 10箱 × 12件`，候选总数为240件。抽取3件时，系统会生成类似“第1托盘第6箱第2件”的三个唯一位置，并保存包装参数、候选总数、规则版本、候选摘要、抽样结果、操作人和时间。结果生成后不允许重复抽取。
